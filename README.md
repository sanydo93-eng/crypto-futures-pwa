# crypto-futures-pwa

Бот торговых сигналов по фьючерсам KuCoin с публикацией в Telegram-канал.

Читает свечи с публичного API KuCoin Futures (ключи биржи **не нужны**),
считает индикаторы, прогоняет стратегию по закрытию каждой свечи и постит
сигнал в канал. Запускается одним `docker compose up`.

## Быстрый старт на сервере

```bash
git clone <repo-url> crypto-futures-pwa
cd crypto-futures-pwa
git checkout claude/server-tg-signals-setup-mxo0y9

./deploy.sh          # создаст .env из шаблона и остановится
nano .env            # вписать TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID
./deploy.sh          # собрать и запустить

docker compose logs -f
```

При старте бот проверяет себя и падает с понятной ошибкой, если что-то не так:
токен Telegram, недоступный канал, несуществующий символ, неподдерживаемый
таймфрейм.

## Telegram

1. Создать бота у [@BotFather](https://t.me/BotFather) → получить токен.
2. Добавить бота в канал **администратором** с правом «Публикация сообщений».
3. `TELEGRAM_CHAT_ID` — `@имя_канала` для публичного канала, либо числовой id
   вида `-1001234567890` для приватного.

Токен живёт только в `.env` на сервере (права `600`, в git не попадает —
см. `.gitignore`). В репозитории секретов нет.

## Символы KuCoin Futures

Именование отличается от спота: биткоин — `XBTUSDTM`, не `BTCUSDT`.

| Актив | Символ |
|-------|--------|
| BTC   | `XBTUSDTM` |
| ETH   | `ETHUSDTM` |
| SOL   | `SOLUSDTM` |

Список всех активных контрактов: `GET https://api-futures.kucoin.com/api/v1/contracts/active`.

Таймфрейм (`GRANULARITY`, минуты) — только из набора, который принимает KuCoin:
`1 5 15 30 60 120 240 480 720 1440 10080`.

## Как это работает

```
KuCoin Futures API ──► closed_klines ──► Strategy.evaluate ──► SignalState ──► Telegram
   (публичный)         (без текущей       (сигнал или None)     (антиспам)
                        незакрытой свечи)
```

- Бот просыпается по закрытию свечи (`CANDLE_LAG_SECONDS` — пауза, чтобы биржа
  успела отдать финальные данные). `POLL_INTERVAL_SECONDS > 0` переключает на
  обычный опрос по таймеру.
- Незакрытая свеча всегда отбрасывается — сигналы не «перерисовываются».
- `SignalState` в `/data/state.json` переживает перезапуск: один и тот же сигнал
  не уйдёт дважды, повтор в ту же сторону ждёт `COOLDOWN_CANDLES`, разворот
  отправляется сразу.
- Ошибка по одной паре не роняет цикл — остальные пары обрабатываются дальше.
- Сеть: ретраи с экспоненциальной задержкой, у Telegram отдельно обрабатывается
  `429 retry_after`.

### Порядок колонок в свечах

Эндпоинт `/api/v1/kline/query` отдаёт голые массивы без имён полей, а порядок
колонок у спота и фьючерсов KuCoin отличается. Вместо того чтобы зашивать один
вариант, клиент определяет раскладку по самим данным (`high` обязан быть не
ниже `open`/`close`, `low` — не выше) и кэширует результат. Если ни одна
раскладка не сходится — бот падает с ошибкой, а не торгует по мусору.

## Стратегия

Сейчас подключена `ema_rsi` — заглушка, чтобы пайплайн работал целиком:
пересечение EMA(12)/EMA(26), фильтр по RSI(14), стоп по ATR, две цели по R:R.
Она **не является готовой торговой системой** и предназначена для замены.

Своя логика добавляется отдельным модулем:

```python
# bot/strategies/my_setup.py
from ..models import Candle, Side, Signal
from .base import Strategy, register

@register("my_setup")
class MySetup(Strategy):
    warmup = 120                      # сколько свечей нужно для расчёта

    def evaluate(self, symbol: str, candles: list[Candle]) -> Signal | None:
        ...                           # candles — закрытые, от старых к новым
        return Signal(symbol=symbol, side=Side.LONG, strategy=self.name,
                      candle_ts=candles[-1].ts, price=candles[-1].close,
                      stop_loss=..., take_profits=[...], reasons=["почему"])
```

Дальше импортировать модуль в `bot/strategies/__init__.py` и поставить
`STRATEGY=my_setup` в `.env`. Любая переменная `STRAT_*` из `.env` приезжает в
стратегию как параметр (`self.param_float("MY_PARAM", 1.5)`), так что
подкручивать цифры можно без пересборки образа.

Стратегия обязана быть stateless: дедуп, кулдаун и отправка — забота раннера.

## Разработка

```bash
python3 -m venv .venv && .venv/bin/pip install httpx pytest
.venv/bin/python -m pytest tests -q
```

29 тестов покрывают индикаторы, разбор обеих раскладок свечей KuCoin,
антиспам-логику с перезапуском, валидацию конфига и поведение стратегии на
walk-forward прогоне.

`DRY_RUN=true` — считать сигналы и писать их в лог, ничего не отправляя в канал.

## Настройки

Все параметры и комментарии — в [`.env.example`](.env.example).

## Дисклеймер

Сигналы носят информационный характер и не являются инвестиционной
рекомендацией. Торговля фьючерсами с плечом сопряжена с риском потери
всех средств.
